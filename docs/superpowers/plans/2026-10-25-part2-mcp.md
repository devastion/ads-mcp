# Part 2 MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve `search_ads`, `get_ad` and `list_niches` over a stateless Streamable HTTP MCP endpoint (`/api/mcp`) that forwards each tool call to v1 REST, sharing auth, rate limit and metering with REST.

**Architecture:** `laravel/mcp` registers the endpoint. Each tool is a thin adapter: validate arguments against the tool schema, map them to a v1 HTTP request (Bearer and `Idempotency-Key` forwarded), then compact the JSON reply into one text block within byte budgets. REST owns validation, cursors, reads and the single rate debit and billing decision. MCP only debits locally for requests that never reach REST (initialize, tools/list, ping, unknown tool, locally rejected arguments). Two additive REST reads are added: `GET /api/v1/ads/{id}` and `GET /api/v1/niches`.

**Tech Stack:** PHP 8.5, Laravel 13.38, `laravel/mcp` (promote from transitive to direct `require`), Pest, Postgres, Larastan level 7, Pint.

**Spec:** `docs/superpowers/specs/2026-10-25-part2-mcp-design.md` (approved by the user on 2026-10-25). Also read `ASSESSMENT.md` Part 2 and 3, `docs/superpowers/specs/2026-10-25-part3-key-rate-limits-metering.md`, and the v0 guard `.agents/skills/v0-contract-guard/SKILL.md`.

## Global Constraints

- Tools: exactly `search_ads`, `get_ad`, `list_niches`, schemas and descriptions verbatim from the spec section "Exact model-facing tool contract". `additionalProperties:false`, enforced at runtime too.
- `search_ads` `limit`: default 5, max 10, maps to REST `per_page`; out of range rejected, never clamped. `niche` is sent as repeated `niche=a&niche=b`.
- `get_ad`: `body_offset` ≥ 0 (Unicode characters), `body_limit` 1–1000 default 1000.
- One text block per result, compact JSON (unescaped Unicode and slashes), no `structuredContent`, no `outputSchema`.
- Byte budgets (measured after serialization): search item ≤ 1,024; search metadata ≤ 4 KiB; search/detail text ≤ 14 KiB; niches text ≤ 2 KiB; whole JSON-RPC response ≤ 32 KiB; error text ≤ 14 KiB. Brand preview ≤ 64 chars / 192 bytes, headline ≤ 120 chars / 512 bytes, `truncated_fields` lists changed fields. Never drop fetched rows, filters, `next_cursor` or the rank note.
- Errors: reuse `App\Enums\ApiErrorCode` strings and `retryable`. Tool errors use `isError:true` with `{error:{code,message,next_step,retryable,details?}}`. Rate limit: `details.retry_after_seconds` (integer) over HTTP 200. Protocol faults (malformed JSON, batch array, unknown method or tool) are JSON-RPC errors. Unknown tool lists the three valid names.
- Auth: original Bearer only, requires `search:read`, rechecked every call, no caching. No `mcp:use` scope. Query-string keys rejected as `api_key_in_query`.
- Idempotency: header-only, forwarded unchanged. No tool argument, no `_meta`. `idempotency_key` argument yields `unknown_parameter` without echoing the value. Never derive a key from JSON-RPC ids.
- Exactly one rate debit per handled operation: REST for forwarded tool calls, MCP's shared-limiter call for local ones. Notifications cost nothing. No MCP-written usage rows.
- REST client: base URL from config only, redirects off, no automatic retries, 2 s connect / 10 s total timeout (config), forward only Authorization, Idempotency-Key and safe content-negotiation headers. Timeout becomes `internal_error` with a "may already be billed" warning.
- JSON-RPC: one request per POST, string ids ≤ 128 UTF-8 bytes or integers, bounded request size, Origin validated when present.
- Structure: `app/Http/Controllers/Mcp/`, `app/Actions/Mcp/`, `app/DTO/`, `app/Http/Middleware/`, `routes/`. No `app/Mcp` root. Files via `php artisan make:* --no-interaction`. New REST reads follow existing v1 layout (`Actions/V1`, `Http/Controllers/V1`, `Http/Requests/V1`, `Http/Resources/V1`).
- Dependency change: only `laravel/mcp` as direct require, via `composer require`, never hand-edit the lockfile.
- v0 frozen: `tests/Feature/Http/Controllers/V0/AdControllerTest.php` is never edited. Run the v0 guard before and after every task that touches shared code.
- Tests: Pest `it()`, behaviour-named, explicit factory values, frozen time. Use Boost `search-docs` before relying on an MCP/HTTP-client API not quoted here.
- Commands from the worktree root:

  ```bash
  php artisan test --compact <path-or-filter>
  vendor/bin/pint --dirty --format agent
  vendor/bin/phpstan analyse --memory-limit=1G
  ```
  The user runs the full suite (`composer test`). No commits unless the user asks; each task ends at a "ready to commit" point.

## Review Focus

- Double rate debit or double billing for a forwarded call (MCP middleware plus REST).
- A page truncated to fit the budget that silently skips rows or loses `next_cursor`.
- Multi-byte, emoji, quote, backslash and control characters at the byte caps and in body slices (offsets are characters, not bytes).
- Single-worker server deadlocking on its own loopback call.
- Revoked key or lost scope still accepted on the next MCP call.
- Corrected-call suggestions that broaden the caller's intent.
