# Part 0 (data model, seed, ingest, v0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ASSESSMENT.md` Part 0: the ads data model, a deterministic seed, a live ingest command, and the frozen `GET /api/v0/ads` endpoint, pinned by a contract test.

**Architecture:** Laravel 13 with the `AGENTS.md` layering. Enums hold the domain values; an `Ad` model owns `daysActive()`; `app/Actions` holds single-task logic (`GenerateAdCopy`, `IngestAds`, `IssueApiKey`, `SearchAds`), and `SearchAds` is shared by design (approach B). v0's HTTP layer (a lenient FormRequest, an invokable controller, an 8-key resource, a key middleware, and an error renderer scoped to `api/v0/*`) is v0-only. Tests run on Postgres.

**Tech Stack:** PHP 8.5, Laravel 13.38, Pest 5.3, Postgres 18, Larastan level 7, Pint.

**Spec:** `docs/superpowers/specs/2026-10-25-part0-v0-design.md` (approved), which implements `ASSESSMENT.md` §0.1–0.4. The guard is `.agents/skills/v0-contract-guard/` (`references/v0-contract.md` §4 lists the quirks, §6 the checklist). Executors read the spec, `ASSESSMENT.md` §0, and the guard.

## Global Constraints

- Every new PHP file comes from `php artisan make:<type> … --no-interaction` (`make:class` for DTOs and Actions, `make:enum` for enums).
- Use Boost `search-docs` before relying on any Laravel or Pest API (Boost works from Task 2 on, once artisan boots). Otherwise read `vendor/`.
- Code structure follows `AGENTS.md`. No new top-level folders; `V0/` subfolders are fine.
- PHP style: curly braces always, constructor promotion, explicit return and parameter types, TitleCase enum cases, PHPDoc with array shapes, no inline comments except for complex logic.
- Tests use `it()`, behaviour-named, with `LazilyRefreshDatabase` (set once in `tests/Pest.php` for `Feature`). Each test creates its own data with factories and explicit values, never seeded data. Time is frozen with `$this->travelTo()`/`freezeTime()`, sleep with `Sleep::fake()`.
- The v0 spec values are verbatim: per_page default `20`, max `100`; page default `1`; error body `{"error":"Invalid request"}` with status `400`; item keys `id, brand, headline, niche, format, status, start_date, days_active`; body keys `data, page, total`; sort `start_date` desc **with no tiebreaker**.
- Seed values: `20000` ads, `300` brands, all 12 niches, ~60% active, start dates over the last `730` days, ~40% null `impression_rank`. Ingest values: 1–5 inserts and 1–2 deactivations per tick, ~30% of inserts backdated 1–90 days.
- Per-task verification commands (from the worktree root):
  ```bash
  php artisan test --compact <test-path>
  vendor/bin/pint --dirty --format agent
  vendor/bin/phpstan analyse
  ```
- One commit per green task. Short imperative messages, no prefixes, no squashing. Never push, merge or rebase.

## Review Focus

1. **The global `ConvertEmptyStringsToNull`/`TrimStrings` middleware:** `q=%20%20` and `api_key=` must not crash (null values). Pinned in Task 11 and Task 10.
2. **Ingest on an empty database (no brands yet):** it must exit non-zero with a "seed first" message, not throw. Pinned in Task 8.
3. **A non-GET method or an unknown sub-path under `/api/v0`** must give the 400 body, while `/api/v1/…` and other paths must keep Laravel's default rendering (the scoping proof). Pinned in Task 10.
4. **Display names with `&` (`Baby & Kids`)** in `niche=` must match when URL-encoded (`Baby%20%26%20Kids`). Pinned in Task 11.
5. **The SIGINT/SIGTERM stop path** can't be signalled from a feature test, so it is verified by hand in Phase 4 (`ads:ingest` run, then Ctrl-C) and recorded. Task 8 covers the loop exit via `--ticks`.

### Task 5: Deterministic seed

**Files:**
- Create: `database/seeders/AdSeeder.php` (`php artisan make:seeder AdSeeder`)
- Modify: `database/seeders/DatabaseSeeder.php` (calls `AdSeeder`)
- Test: `tests/Feature/Database/Seeders/AdSeederTest.php`

**Interfaces — Consumes:** `GenerateAdCopy`, `Niche`, `AdFormat`, `AdStatus`. **Produces:** `AdSeeder`.

Approach: one `Randomizer(new Mt19937(SEED))` with a constant seed, no Faker, and every date relative to `today()`. `Ad::query()->truncate()` (Postgres `restart identity`) runs first, then rows are built in memory and inserted in chunks of 1000.
- Brands: 300 deterministic, unique `brand_name`s with `brand_id` 1–300. Each brand gets one niche, assigned round-robin so all 12 are covered, and an uneven ad count (some large, some small) summing to exactly 20000.
- Status: ~60% active. `start_date = today - rand(0..729)`. An inactive ad gets `end_date` in `[start_date, today]`.
- `impression_rank`: per brand, ~40% null, and the rest numbered `1..k` in shuffled order.
- `countries`: 1–4 distinct codes from a fixed list of ISO-2 codes.
- `discovered_at`: deterministic (no `now()` seconds), at or after `start_date` 00:00 and no later than `today` 00:00.
- `created_at` and `updated_at` are set to `discovered_at`.

- [ ] **Step 1: Write the failing tests**, with time frozen at `2026-10-25 12:00:00`:
  - `it('seeds 20000 ads across 300 brands and all 12 niches')`.
  - `it('seeds roughly 60% active ads with end dates only on inactive ads')`: active share in `[0.55, 0.65]`; `whereNull('end_date')` count equals the active count; no `end_date < start_date`.
  - `it('spreads start dates over the last two years')`: min ≥ `today-729`, max ≤ `today`, and each of the 8 quarters has ads.
  - `it('leaves roughly 40% of impression ranks empty and ranks each brand from 1 without gaps')`: null share in `[0.35, 0.45]`; per brand, the non-null ranks equal `range(1, k)`.
  - `it('uses every niche keyword in some seeded headline')`.
  - `it('produces identical data when run twice on the same day')`: seed, then checksum `md5(string_agg(...order by id))` over every spec column (excluding the timestamps), seed again, and the checksums are equal. Also assert `min(id)=1`.
